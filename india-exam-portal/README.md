## ✨ Features

| Feature | Detail |
|---|---|
| 👁️ **File Open** | PDF browser mein seedha preview hoti hai |
| ⬇️ **File Download** | Ek click mein phone/PC mein save |
| ⬆️ **File Upload** | Drag & Drop se koi bhi file upload karo |
| 🔍 **Search & Filter** | Exam, subject, type se filter karo |
| 🗂️ **12 Categories** | UPSC, SSC, JEE, NEET, Banking, Railway... |
| 📱 **Responsive** | Mobile + Tablet + Desktop sab pe chalti hai |
| 💾 **Data Save** | Browser mein files save rehti hain |
| 🆓 **100% Free** | Koi login nahi, koi payment nahi |

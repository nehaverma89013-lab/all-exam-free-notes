# 📚 All Exam Free Notes & Previous Year Papers (India Exam Portal)

Welcome to **All Exam Free Notes**, an open-source educational platform dedicated to providing free, high-quality study materials, reference books, and previous year question papers (PYQs) for various competitive exams across India.

## 🎯 Project Vision
Many students preparing for competitive exams cannot afford expensive coaching or paid test series. This project aims to democratize exam preparation by creating an open, accessible, and well-structured repository of study resources.

## ✨ Key Features
* **📝 Comprehensive Study Notes:** Subject-wise and topic-wise notes for quick revision.
* **📄 Previous Year Question Papers (PYQs):** Authentic past papers to help students understand exam patterns and difficulty levels.
* **📖 Free Reference Books & PDFs:** Curated educational materials and standard books.
* **⚡ Fast & Accessible Web Portal:** Clean, mobile-friendly user interface (`india-exam-portal`) for seamless reading and downloading.

## 📂 Repository Structure
* `india-exam-portal/` - Contains the core source code, assets, and frontend components for the web portal.

## 🤝 How to Contribute

4. Commit your changes and open a **Pull Request**.
